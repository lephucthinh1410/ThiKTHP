Bài 2 (20 điểm): Todo + LocalStorage

Nhập công việc → thêm → sửa/xóa. Dữ liệu lưu LocalStorage.

Giải thích logic tư duy (ngắn gọn)

  • State là mảng todos (id, text, createdAt).
  • Mỗi thao tác (add/edit/del) chỉ sửa mảng → save() → render().
  • Render hiệu quả: dùng innerHTML 1 lần thay vì tạo từng node nhiều lần.
  • Event delegation: gắn 1 listener lên list để bắt nút sửa/xóa → nhẹ hơn.
